# Polar provenance

The NACA 0012 polar files in `naca0012/` are **synthetic**, not raw
Sheldahl-Klimas tables. They were generated by
`archive/old_versions/gen_polars.py` and are approximately:

- Linear lift slope in the attached region, matched to thin-airfoil at
  the nominal Reynolds number.
- Post-stall lift following `Cl ~ 0.85·sin 2α` from roughly 30° to 75°,
  with drag rising to ~2 at 90°.
- Zero pitching moment (`Cm = 0`) at all angles.

Files:

| File | Re |
|---|---|
| `polars_naca0012_Re_100000.csv`  | 1 × 10⁵ |
| `polars_naca0012_Re_200000.csv`  | 2 × 10⁵ |
| `polars_naca0012_Re_400000.csv`  | 4 × 10⁵ |
| `polars_naca0012_Re_1000000.csv` | 1 × 10⁶ |

## Limitations

1. **Not experimentally derived.** Real SAND80-2114 data has secondary
   stall peaks, non-monotonic structure in the deep-stall region, and a
   pitching-moment coefficient that moves the centre of pressure. None
   of that is present here.

2. **`Cm = 0` is a real modelling choice**, not just missing data. The
   pitch moment in this project is computed from lift acting at a fixed
   arm, with no Cm contribution. In attached flow this is fine (Cm ≈ 0
   at the quarter chord). In deep stall it is not, and this may
   contribute to the instability seen when the finite-span correction
   is un-floored (see the Finite-span correction paragraph in the main
   README).

3. **Reynolds interpolation** uses a bilinear fit in (log Re, α), which
   is standard but hides the real Re-dependent shape changes in the
   stall band.

## To use real data

Replace the four CSVs with digitised Sheldahl-Klimas tables at the same
Re, keeping the three-column format (`alpha, Cl, Cd`). The loader in
`vawt_core.py` reads any file with that header. Once real tables are in
place, extend the loader to read a fourth column for Cm and wire it
through the pitch-moment calculation.
