# Contributing

This is a solo research project (a numerical lab for the Sharp cycloturbine), not a library. Code contributions are not being actively sought.

## Bug Reports & Corrections

These **are** welcome. Open an issue with a minimal reproducer.

## Pull Requests

Open an issue first and describe the change. Unsolicited PRs are likely to be closed, especially ones that:

- retune polar tables or regression goldens to make a test pass
- change physics constants without a derivation and a reference
- refactor for style

## What I Am Not Looking For

- new features, models, or dependencies
- reformatting / renaming / cleanup PRs
- AI-generated diffs the author cannot explain line-by-line

## On AI Assistance

The author uses AI assistance and says so in the README. AI-generated contributions the author cannot defend in their own words will not be accepted.
