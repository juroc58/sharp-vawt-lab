# Polar provenance

The NACA 0012 polar files in `naca0012/` are **not raw experimental data**.
They are generated by `scripts/gen_real_polars.py` and mix three sources:

| Region | Source |
|---|---|
| `\|alpha\| <= 20 deg` (Cl, Cd) | NeuralFoil 0.3.3, the XFOIL-trained neural network (`n_crit = 9`, `xlarge` model) |
| `20 < \|alpha\| < 45 deg` | Smoothstep blend to the flat-plate deep-stall model |
| `\|alpha\| >= 45 deg` (Cl, Cd) | Flat-plate model, `CL = 0.65 sin(2a)`, `CD = 1.66 sin^2(a) + 0.02`, anchored to Sheldahl & Klimas (1981) SAND80-2114 |
| Cm (all angles) | Synthetic Abbott & von Doenhoff trend; **not measured** |

The attached-flow drag is the part that matters most for the rotor
calculation, because the blades spend most of a revolution there. The
previous hand-fitted tables over-predicted it by 1.6–3.3x (typically
~2.5x; e.g. CD = 0.021 instead of ~0.010 at Re = 10⁶, α = 6°). NeuralFoil
gives the XFOIL-trained values; the committed tables are generated from it.

`provenance.json` records the NeuralFoil version, `n_crit`, model size,
CST fit error and the Reynolds numbers. Regenerate with:

```bash
pip install neuralfoil
python3 scripts/gen_real_polars.py
```

The generator needs only `numpy` and `neuralfoil`. When AeroSandbox is not
installed it injects a minimal NumPy-backed shim for the few helpers
NeuralFoil's core imports; this is documented in the script.

Files:

| File | Re |
|---|---|
| `polars_naca0012_Re_100000.csv`  | 1 × 10⁵ |
| `polars_naca0012_Re_200000.csv`  | 2 × 10⁵ |
| `polars_naca0012_Re_400000.csv`  | 4 × 10⁵ |
| `polars_naca0012_Re_1000000.csv` | 1 × 10⁶ |

`scripts/gen_real_polars_v2.py` is a deprecated alias for the same
generator.

## Limitations

1. **Not experimentally derived.** The attached-flow Cl/Cd are a surrogate
   for XFOIL, not wind-tunnel measurements. The deep-stall curve is an
   analytic flat-plate model. Real SAND80-2114 data has secondary stall
   peaks, hysteresis and non-monotonic structure that are not present here.

2. **Cm is synthetic.** The tables contain a smooth Abbott & von Doenhoff
   trend (near zero attached, about −0.05 through the stall band). It is not
   measured. The core model uses Cm to compute the pitch moment
   `Qa_cm = q * Cm * c`, which affects both the pitch moment and, via hub
   reaction, the rotor torque.

3. **Reynolds interpolation** uses a bilinear fit in (log Re, α). That is
   standard but hides the real Re-dependent shape changes in the stall band.

## To use real data

Replace the four CSVs with digitised Sheldahl–Klimas tables at the same Re,
keeping the four-column format (`alpha_deg, Cl, Cd, Cm`). The loader in
`vawt_core.py` reads any file with that header and uses the fourth column
for Cm.
