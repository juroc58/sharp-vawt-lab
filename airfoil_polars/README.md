# Polar provenance

The NACA 0012 polar files in `naca0012/` are synthetic, generated by
`scripts/gen_real_polars_v2.py`. They include four columns (`alpha_deg,
Cl, Cd, Cm`) with pitching-moment data inspired by Abbott & von Doenhoff
and SAND80-2114 trends.

Key characteristics:

- Realistic Cl_alpha variation with Reynolds number
- Accurate stall characteristics (onset ~12-15°, peak, post-stall)
- Realistic Cd polar (laminar bucket, turbulent rise)
- Non-zero Cm with representative values (NACA 0012 has Cm ~ -0.02 to -0.05 at stall)
- Proper deep-stall behavior (Cl drop, Cd rise, Cm negative peak)

## Limitations

1. **Not experimentally derived.** Real SAND80-2114 data has secondary
   stall peaks, non-monotonic structure in the deep-stall region, and a
   pitching-moment coefficient that moves the centre of pressure. None
   of that is present here.

2. **Cm is synthetic.** The polars include Cm values generated from
   Abbott & von Doenhoff data, but they are not measured values. The
   core model now uses Cm to compute the pitch moment Qa_cm = q * Cm * c,
   which affects both the pitch moment and (via hub reaction) the rotor
   torque.

3. **Reynolds interpolation** uses a bilinear fit in (log Re, α), which
   is standard but hides the real Re-dependent shape changes in the
   stall band.

## To use real data

Replace the four CSVs with digitised Sheldahl-Klimas tables at the same
Re, keeping the four-column format (`alpha_deg, Cl, Cd, Cm`). The loader
in `vawt_core.py` reads any file with that header and uses the fourth
column for Cm.
