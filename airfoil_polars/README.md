# Polar provenance

The NACA 0012 polar files in `naca0012/` are **not raw experimental data**.
They are generated by `scripts/gen_real_polars.py` and mix three sources:

| Region | Cl, Cd | Cm |
|---|---|---|
| `\|alpha\| <= 20 deg` | NeuralFoil 0.3.3, the XFOIL-trained neural network (`n_crit = 9`, `xlarge` model) | NeuralFoil `CM` (quarter-chord, positive nose-up) |
| `20 < \|alpha\| < 45 deg` | Smoothstep blend to the flat-plate deep-stall model | Smoothstep blend to the synthetic deep-stall trend |
| `\|alpha\| >= 45 deg` | Flat-plate model, `CL = 0.65 sin(2a)`, `CD = 1.66 sin^2(a) + 0.02`, anchored to Sheldahl & Klimas (1981) SAND80-2114 | Synthetic Abbott & von Doenhoff trend; **not measured** |

The attached-flow drag is the part that matters most for the rotor
calculation, because the blades spend most of a revolution there. The
previous hand-fitted tables over-predicted it by 1.6–3.3x (typically
~2.5x; e.g. CD = 0.021 instead of ~0.010 at Re = 10⁶, α = 6°). NeuralFoil
gives the XFOIL-trained values; the committed tables are generated from it.

**Cm convention.** NeuralFoil reports the quarter-chord pitching moment in
the standard aircraft sense: positive is nose-up. The solver uses the same
sense in `Qa_cm = q * Cm * c`, so no sign flip is applied. Negative
incidence is mirrored with odd symmetry (`Cm(-α) = -Cm(α)`).

NeuralFoil's attached-flow Cm is a surrogate output, not a physical
constraint. For a symmetric NACA 0012 the true quarter-chord Cm is close to
zero in attached flow; the network instead returns a non-monotonic scatter
(at Re = 10⁶ it moves from about −0.008 to +0.047 over 0–20°). Those raw
values are kept rather than smoothed, because smoothing would invent
structure the surrogate does not have. The scatter matters: the passive
pitch machine uses Cm directly, and replacing the old synthetic near-zero
trend with the network values moves its operating point (see the CHANGELOG
v3.3.1 entry). Deep-stall Cm remains an analytic trend because NeuralFoil's
post-stall moment is not validated.

`provenance.json` records the NeuralFoil version, `n_crit`, model size,
CST fit error, Reynolds numbers and the Cm convention. Regenerate with:

```bash
pip install neuralfoil
python3 scripts/gen_real_polars.py
```

The generator needs only `numpy` and `neuralfoil`. When AeroSandbox is not
installed it injects a minimal NumPy-backed shim for the few helpers
NeuralFoil's core imports; this is documented in the script.

## Limitations

1. **Not experimentally derived.** The attached-flow Cl, Cd and Cm are a
   surrogate for XFOIL, not wind-tunnel measurements. The deep-stall curve
   is an analytic flat-plate model. Real SAND80-2114 data has secondary
   stall peaks, hysteresis and non-monotonic structure that are not present
   here.

2. **Attached-flow Cm is network output.** It is not forced to be zero for
   a symmetric section, and it is not monotonic through the attached range.
   The core model uses Cm to compute the pitch moment `Qa_cm = q * Cm * c`,
   which affects both the pitch moment and, via hub reaction, the rotor
   torque. Section 12 of `docs/derivation.md` lists this as a model-form
   limitation.

3. **Low-Re lift is surrogate output.** At Re = 1e5 the attached Cl reaches
   0.445 at 2° (slope ≈ 12.7/rad, about twice the thin-airfoil limit of
   2π) and peaks near 0.98 at 10° before falling to 0.68 at 12°. NeuralFoil
   is an XFOIL-trained network and is least reliable off its training
   Reynolds numbers and in post-stall; treat Re = 1e5 attached values as
   indicative and compare against measured low-Re NACA 0012 data before
   using them quantitatively.

   `scripts/check_polars.py` prints a warning report for this pattern
   (attached slope > 1.15·2π, non-monotone Cl before stall, Cm sign
   changes). It is deliberately not a CI failure.

4. **Post-stall reliability and `n_crit`.** NeuralFoil is a surrogate trained
   mostly on XFOIL; it is least reliable after stall. The tables use
   `n_crit = 9`, a clean-tunnel e⁹ transition value. Rotor blades in
   atmospheric turbulence usually have a lower effective `n_crit`, so the
   attached-flow polars are optimistic for field operation. `n_crit` is
   recorded in `provenance.json`.

5. **`polar_variant="smoothed_lowRe"` is a model-form sensitivity option,
   not data.** For tables with Re ≤ 1 × 10⁵ and |α| ≤ 20°, it caps the lift
   magnitude by `2π·1.1·sin(α)cos(α)` and then enforces monotone Cl in
   |α| from 0 to 20°, removing the 12° bubble dip. It leaves Re > 10⁵ and
   the Cd/Cm columns unchanged. It exists so the UQ can test how much a
   result depends on the low-Re surrogate artefact; the default remains
   `"neuralfoil"` (raw table).

6. **Deep-stall constants are provisional.** The flat-plate amplitudes
   (`CL = 0.65 sin 2α`, `CD = 1.66 sin²α + 0.02`, synthetic Cm) are named
   constants in `scripts/gen_real_polars.py`. They are literature-typical
   trends anchored to Sheldahl & Klimas (1981) SAND80-2114, not a fit to
   digitised data in this repository, and are marked provisional/unverified.

7. **Reynolds interpolation** uses a bilinear fit in (log Re, α). That is
   standard but hides the real Re-dependent shape changes in the stall band.

## To use real data

Replace the four CSVs with digitised Sheldahl–Klimas tables at the same Re,
keeping the four-column format (`alpha_deg, Cl, Cd, Cm`). The loader in
`vawt_core.py` reads any file with that header and uses the fourth column
for Cm. If measured Cm is available, it should be used in place of both the
NeuralFoil attached values and the synthetic deep-stall trend.
