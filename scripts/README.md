# `scripts/` directory

## What's in here

- **Analysis scripts** — reproduce the README figures and tables:
  `validate_ham.py`, `validate_ds_off.py`, `compute_aep.py`,
  `compute_aep_turbulent.py`, `uncertainty.py`, `spearman_sensitivity.py`,
  `diag_qa.py`, `passive_sweeps.py`, `passive_sharp.py`,
  `plot_validation.py`, `render_animation.py`.

- **Optimisers** — `optimize_passive.py`, `optimize_actuator.py`,
  `optimize_scaleup.py`.

- **JSON result files** — reproducible snapshots of the outputs quoted in
  the README. Each is regenerated by running its corresponding script:

  | JSON file | Regenerated by |
  |---|---|
  | `aep_results.json` | `compute_aep.py` |
  | `aep_turbulent.json` | `compute_aep_turbulent.py` |
  | `optimization_passive.json` | `optimize_passive.py` |
  | `optimization_scaleup.json` | `optimize_scaleup.py` |
  | `uncertainty_results.json` | `uncertainty.py` |
  | `spearman_results.json` | `spearman_sensitivity.py` |

  They are committed so that a reviewer can inspect the raw numbers behind
  each README claim without re-running the simulations.  If a script's
  outputs change (e.g. after a physics update), regenerate its JSON and
  commit the diff together with the README update.
