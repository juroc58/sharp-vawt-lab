# `scripts/` directory

## What's in here

- **Analysis scripts** — reproduce the README figures and tables:
  `validate_ham.py`, `validate_ds_off.py`, `compute_aep.py`,
  `compute_aep_turbulent.py`, `uncertainty.py`, `spearman_sensitivity.py`,
  `diag_qa.py`, `passive_sweeps.py`, `passive_sharp.py`,
  `plot_validation.py`, `render_animation.py`.

- **Optimisers** — `optimize_passive.py`, `optimize_actuator.py`,
  `optimize_scaleup.py`.

- **JSON result files** — reproducible snapshots of the outputs quoted in
  the README. Each is regenerated by running its corresponding script:

  | JSON file | Regenerated by |
  |---|---|
  | `aep_results.json` | `compute_aep.py` |
  | `aep_rigid_fair.json` | `compute_aep_rigid_fair.py` |
  | `aep_turbulent.json` | `compute_aep_turbulent.py` |
  | `optimization_passive.json` | `optimize_passive.py` |
  | `optimization_scaleup.json` | `optimize_scaleup.py` |
  | `optimization_actuator.json` | `optimize_actuator.py` (reference design point; see the file's `_note`) |
  | `uncertainty_results.json` | `uncertainty.py` |
  | `spearman_results.json` | `spearman_sensitivity.py` |

  They are committed so that a reviewer can inspect the raw numbers behind
  each README claim without re-running the simulations.  If a script's
  outputs change (e.g. after a physics update), regenerate its JSON and
  commit the diff together with the README update.

## Design points used across the scripts

Several scripts embed a `BASE`/`DESIGN` dictionary. They are **not** all
the same geometry — each one is the appropriate reference for its own
figure, and none is a repo-wide default. This table is the canonical
map, so a value that looks inconsistent is explained rather than
assumed to be a bug.

| Design point | Used by | R | c | ar | sp | mc | dcw | Notes |
|---|---|---|---|---|---|---|---|---|
| Sharp-inspired CPPC | `compute_aep*.py`, UQ `sharp_cppc` | 0.60 | 0.14 | 0.50 | 0.25 | 0.002 | 0.30 | headline CPPC geometry |
| CPPC pitch-sign case | `diag_qa.py`, `passive_sweeps.py` | 0.60 | 0.1176 | 0.50 | 0.25 | 0.004 | −0.10 | manual-sweep optimum, Cp ≈ 0.36 |
| Sharp-spec sweep case | `passive_sharp.py` | 0.60 | 0.1176 | 0.50 | 0.25 | 0.008 | 0.50 | Sharp's published cw range |
| Passive optimum | `optimize_passive.py`, UQ `optimised_passive` | 0.60 | 0.157 | 0.797 | 0.153 | 0.0165 | 0.012 | mass-balanced optimum |
| Scale-up optimum | `optimize_scaleup.py`, UQ `scaleup` | 2.72 | 0.386 | 0.312 | 0.218 | 2.69 | −0.194 | H/R at upper bound |
| Actuator / DS case | `optimize_actuator.py`, `validate_ds_off.py`, `render_animation.py` | 0.60 | 0.1176 | 0.50 | 0.25 | 0.008 | 0.50 | prescribed-pitch upper bound |
| Ham 1979 rig | `validate_ham.py`, UQ `ham_1979` | 1.83 | 0.305 | 0.0 | 0.25 | — | — | Ham's own model class |

The `optimised_passive` and `scaleup` rows take their exact values from
`uncertainty.py`'s `ANCHORS`, which is the single place those two
optima are frozen for the UQ study.
