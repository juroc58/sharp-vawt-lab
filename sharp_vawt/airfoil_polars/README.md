# Polar provenance

The NACA 0012 polar files in `naca0012/` are **not raw experimental data**.
They are generated by `scripts/gen_real_polars.py` and mix three sources:

| Region | Cl, Cd | Cm (default) | Cm (neuralfoil_cm variant) |
|---|---|---|---|
| `\|alpha\| <= 20 deg` | NeuralFoil 0.3.3, XFOIL-trained (`n_crit = 9`, `xlarge`); lift slope clamped at 1.15·2π, monotone Cl enforced | **Cm = 0** (physical symmetric-section value) | NeuralFoil `CM` (quarter-chord, positive nose-up) |
| `20 < \|alpha\| < 45 deg` | Smoothstep blend to flat-plate deep-stall model | Centre-of-pressure shift: x_cp 0.25c → 0.5c, Cm = -CN·(x_cp - 0.25) | Smoothstep blend to synthetic deep-stall trend |
| `\|alpha\| >= 45 deg` | Flat-plate model, `CL = 0.65 sin(2a)`, `CD = 1.66 sin^2(a) + 0.02`, anchored to Sheldahl & Klimas (1981) SAND80-2114 | Synthetic deep-stall trend (provisional) | Synthetic deep-stall trend |

The attached-flow drag is the part that matters most for the rotor
calculation, because the blades spend most of a revolution there. The
previous hand-fitted tables over-predicted it by 1.6–3.3x (typically
~2.5x; e.g. CD = 0.021 instead of ~0.010 at Re = 10⁶, α = 6°). NeuralFoil
gives the XFOIL-trained values; the committed tables are generated from it.

**Cm convention.** NeuralFoil reports the quarter-chord pitching moment in
the standard aircraft sense: positive is nose-up. The solver uses the same
sense in `Qa_cm = q * Cm * c`, so no sign flip is applied. Negative
incidence is mirrored with odd symmetry (`Cm(-α) = -Cm(α)`).

**Default Cm is zero in attached flow.** For a symmetric NACA 0012 the true
quarter-chord Cm is close to zero in attached flow. The default variant
(`polar_variant="neuralfoil"`) enforces Cm = 0 for |α| ≤ 20° and uses a
centre-of-pressure shift model (x_cp: 0.25c → 0.5c) post-stall. The raw
NeuralFoil Cm (which has sign changes and scatter) is available as the
`polar_variant="neuralfoil_cm"` sensitivity variant. Deep-stall Cm
remains an analytic trend because NeuralFoil's post-stall moment is not
validated.

`provenance.json` records the NeuralFoil version, `n_crit`, model size,
CST fit error, Reynolds numbers and the Cm convention. Regenerate with:

```bash
pip install neuralfoil
python3 scripts/gen_real_polars.py
```

The generator needs only `numpy` and `neuralfoil`. When AeroSandbox is not
installed it injects a minimal NumPy-backed shim for the few helpers
NeuralFoil's core imports; this is documented in the script.

Files:

| File | Re |
|---|---|
| `polars_naca0012_Re_100000.csv`  | 1 × 10⁵ |
| `polars_naca0012_Re_200000.csv`  | 2 × 10⁵ |
| `polars_naca0012_Re_400000.csv`  | 4 × 10⁵ |
| `polars_naca0012_Re_1000000.csv` | 1 × 10⁶ |

generator.

## Limitations

1. **Not experimentally derived.** The attached-flow Cl, Cd and Cm are a
   surrogate for XFOIL, not wind-tunnel measurements. The default Cl has
   its slope clamped at 1.15·2π and monotonicity enforced to 20°; the
   default Cm is set to zero in attached flow (physical symmetric-section
   value). The deep-stall curve is an analytic flat-plate model. Real
   SAND80-2114 data has secondary stall peaks, hysteresis and
   non-monotonic structure that are not present here.

2. **Low-Re lift is surrogate output.** At Re = 1e5 the clamped attached
   Cl reaches a slope of 1.15·2π at low α and is monotone to 20°. The
   raw NeuralFoil values (with steeper slope and a 12° bubble dip) are
   available via the `neuralfoil_cm` variant for sensitivity analysis.
   NeuralFoil is an XFOIL-trained network and is least reliable off its
   training Reynolds numbers and in post-stall.

3. **Post-stall reliability and `n_crit`.** NeuralFoil is a surrogate trained
   mostly on XFOIL; it is least reliable after stall. The tables use
   `n_crit = 9`, a clean-tunnel e⁹ transition value. Rotor blades in
   atmospheric turbulence usually have a lower effective `n_crit`, so the
   attached-flow polars are optimistic for field operation. `n_crit` is
   recorded in `provenance.json`.

4. **`polar_variant="smoothed_lowRe"` is a model-form sensitivity option,
   not data.** For tables with Re ≤ 1 × 10⁵ and |α| ≤ 20°, it caps the lift
   magnitude by `2π·1.1·sin(α)cos(α)` and then enforces monotone Cl in
   |α| from 0 to 20°, removing the 12° bubble dip. It leaves Re > 10⁵ and
   the Cd/Cm columns unchanged. It exists so the UQ can test how much a
   result depends on the low-Re surrogate artefact; the default remains
   `"neuralfoil"` (clean table).

5. **`polar_variant="neuralfoil_cm"` is a sensitivity variant.** It uses
   the raw NeuralFoil CM values (with attached-flow sign changes) for
   sensitivity analysis only. It is not the default because the raw
   NeuralFoil CM is not a physical constraint for a symmetric section.

6. **Deep-stall constants are provisional.** The flat-plate amplitudes
   (`CL = 0.65 sin 2α`, `CD = 1.66 sin²α + 0.02`, synthetic Cm) are named
   constants in `scripts/gen_real_polars.py`. They are literature-typical
   trends anchored to Sheldahl & Klimas (1981) SAND80-2114, not a fit to
   digitised data in this repository, and are marked provisional/unverified.

7. **Reynolds interpolation** uses a bilinear fit in (log Re, α). That is
   standard but hides the real Re-dependent shape changes in the stall band.

## To use real data

Replace the four CSVs with digitised Sheldahl–Klimas tables at the same Re,
keeping the five-column format (`alpha_deg, Cl, Cd, Cm_default, Cm_neuralfoil`).
The loader in `vawt_core.py` reads the fourth column for the default Cm and
the fifth column for the `neuralfoil_cm` variant. If measured Cm is available,
it should be used in place of both the default and NeuralFoil Cm.
